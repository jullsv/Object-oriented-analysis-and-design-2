# Лабораторная работа №1

**Паттерн:** декоратор (Decorator)

**Предметная область:** создание и кастомизация мемов для социальных сетей.

**Описание проблемы:**
Пользователю необходимо создавать уникальные мемы, комбинируя базовое изображение с различными элементами: текстовыми надписями, фильтрами, рамками, стикерами и водяными знаками.
При использовании наследования для реализации всех возможных комбинаций потребовалось бы создать экспоненциальное количество классов: TextMeme, FilteredMeme, TextBorderMeme, TextFilteredStickerMeme и т.д. Кроме того, пользователь должен иметь возможность динамически добавлять и удалять элементы в процессе редактирования, что невозможно при статическом наследовании.

**Решение:**
В проекте паттерн Decorator используется для динамического добавления обязанностей объекту изображения без изменения его класса. Вместо создания новых подклассов для каждой комбинации эффектов, система оборачивает базовый объект изображения в декораторы, каждый из которых добавляет свою функциональность.
Базовый компонент MemeComponent определяет интерфейс для работы с изображением. Конкретный компонент MemeImage хранит исходное изображение. Абстрактный декоратор MemeDecorator хранит ссылку на компонент и делегирует ему запросы. Конкретные декораторы (TextDecorator, FilterDecorator, BorderDecorator, StickerDecorator, WatermarkDecorator) переопределяют метод getImage(), добавляя свою обработку к результату базового компонента.
